# CropNova Dashboard

A modern, responsive prototype dashboard for the CropNova smart farming concept.

## Run locally

1. Install Node.js LTS: https://nodejs.org/
2. Open a terminal in this project folder.
3. Run:

```bash
npm install
npm run dev
```

4. Open the localhost URL Vite shows, usually `http://localhost:5173/`.

## Prototype notes

- Data is mock/demo data for the prototype.
- Plant imagery is loaded from Unsplash URLs, so an internet connection is useful for the photos.
- Settings, profile menu, theme toggle, alerts, zone drawer and navigation are interactive.
- The UI is intentionally designed around navy/blue highlights, orange attention states and red risk states rather than the previous green-heavy palette.
